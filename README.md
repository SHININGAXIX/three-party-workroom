# 三方工作间

把你、DeepSeek Harness（DS）和 Codex 放在一个本机聊天页中。DS 与 Codex 沿用各自的固定会话；协调器保存共同发言、已确认约束和附件索引，并在调用下一位成员时传递尚未读到的发言。

> **实验性 Windows 项目。** 这是个人制作的本地原型，不是 OpenAI 或 DeepSeek 官方产品。DSH 和 Codex 桌面端的本地接口可能随版本变化。请先用不含敏感资料的测试会话试运行。

## 能做什么

- 一轮按 **DS → Codex** 顺序讨论，或只调用其中一位；另一位下次调用时会看到新增发言。
- 固定会话、共同记录、人工确认约束；模型建议不会自动变成人类决定。
- 上传 TXT、Markdown、DOCX、可复制文字的 PDF；按需提取文字。图片与扫描件不做 OCR。
- 下载双方交付的文件；查找历史发言、按发言人筛选、逐条收起或展开长回复。
- 显示连接、响应和停止状态；对送达不确定的回合先核对，再决定是否重试。

## 环境

- Windows 10/11、Node.js 20 或更新版本。
- 已安装并登录的 DeepSeek Harness，且已有一条要沿用的会话。
- 已安装并登录的 Codex 桌面应用及其本机 Codex CLI。桌面会话桥接依赖当前版本的本地工具接口，属于实验功能。
- Python 3 用于公开网页及 PDF/DOCX 文字提取。DOCX 使用标准库；PDF 需要安装 pymupdf 或 pypdf，否则原文件仍可保存和下载。

工作间默认只监听 127.0.0.1:18741。它会把你发送给模型的文字和选中的附件文字交给相应服务；网页读取只针对本轮明确引用的公开链接。

## 开始使用

1. 下载或克隆此仓库，启动 DeepSeek Harness 和 Codex 桌面应用。
2. 双击 **启动工作间.cmd**。首次运行会列出 DSH 的现有会话，输入要沿用的编号，并在本机生成被 Git 忽略的 config.json。
3. 浏览器打开本机工作间。先用一条不含个人资料的消息试验 **只请 DS 回答**，再试验 **只请 Codex 回答**。

如果你已有一条专用 Codex 会话，可在首次设置时填写它的 UUID。未填写时，工作间会尝试通过本机 Codex CLI 创建并保存一条固定会话。Codex 桌面端若同时占用该会话，CLI 可能报告写入冲突；工作间不会为规避冲突偷偷更换会话。

如果 DSH 日志不在默认位置，先设置环境变量 DSH_LOG_PATH 为它的 harness.log 完整路径。若 Python 不在 PATH，设置 WORKROOM_PYTHON 为 python.exe 的完整路径。需要代理时，在本机 config.json 的 proxy 字段填写代理地址；不要把含真实配置的文件提交到 Git。

### 可选：Codex 桌面会话桥接

默认回退路径是 CLI，能否使用取决于本机版本和登录状态。若你清楚自己安装的 codex-app-tools 本地通道，且有另一条获授权的 Codex 调用会话，可在 config.json 中设置 codexThreadId（被续接的专用会话）与 codexCallerThreadId（调用方会话）。桥接使用未公开保证稳定的本地协议，升级后应重新验证；它不适合作为无人值守服务。没有这些条件时留空，由工作间尝试 CLI。

## 数据与安全

config.json、.runtime/、memory/、uploads/、artifacts/ 等本机状态已被 Git 忽略。**不要直接把运行中的整个工作间目录上传到 GitHub**：聊天记录、附件、调用输入和本机授权信息都可能在里面。发布前仍要检查 Git 的待提交文件；.gitignore 不是安全审计。

工作间只接受本机访问，并用本机生成的随机令牌保护网页。它不是互联网服务，不应通过端口转发、反向代理或公网隧道对外开放。不要把 .runtime/token、带 ?token= 的启动链接或真实 config.json 发给别人。

停止 Codex 桌面会话时，工作间只能发送停止请求并拒绝发布取消回合的迟到回复；这不保证模型立刻停下。需要立即停止时，在 Codex 桌面端手动停止。

## 开发与检验

运行 npm test 执行本地通信测试。测试使用临时目录和模拟会话，不会给真实 DS 或 Codex 发消息。源码主要是 Node.js 标准库、Python 标准库和一个本地 HTML 页面；没有 npm 安装步骤。

当前限制：只在 Windows 上使用过；外部产品更新可能改变本地接口；自动读取网页不执行脚本，也不处理登录页；完整发言保存在本机，但模型的上下文窗口仍有限。欢迎提交问题和改进，提出问题时请先删去会话 ID、令牌、文档内容和个人路径。
